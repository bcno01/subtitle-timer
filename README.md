# 字幕タイミング打刻ツール

動画を再生しながらタイミングを打刻して、SRT/VTT字幕ファイルを作るツールです。
ブラウザだけで動作し、サーバーやアカウントは不要です。

**公開URL**: https://bcno01.github.io/subtitle-timer/

## 使い方

1. 字幕にするテキストを貼り付ける(改行ごと、または句点ごとに1行の字幕として扱う)
2. ローカルの動画ファイルを選択する
3. 「タイミング打刻を開始」→ 動画を再生しながら、その行を読むタイミングで `Space` キー(またはボタン)を押す
   - 押すたびに次の行へ自動で進む
   - `←` / `→` で5秒戻る/進む
   - 間違えたら「1つ前を取り消す」でやり直せる
4. 動画の下に表示される字幕プレビュー(CC)で、実際に字幕ONにしたときの見え方を確認できる
5. SRT または VTT を選んでダウンロード

## インストール(PWA)

このアプリはPWAとして端末にインストールできます。

- **Safari(Mac)**: 共有メニュー →「Dockに追加」
- **Chrome**: アドレスバーのインストールアイコンから追加

インストールすると、オフラインでも起動できます(打刻には動画ファイルの選択が別途必要です)。

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要)
- Service Workerでアプリ本体をキャッシュ(`sw.js`)
- GitHub Actionsで`main`ブランチへのpush時に自動デプロイ(`.github/workflows/pages.yml`)
